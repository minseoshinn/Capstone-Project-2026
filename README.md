# Capstone-Project-2026
Energy-based workload quantification and fatigue-aware sequencing system for last-mile delivery couriers, including live energy heatmap, dashboard, app for courier devices. 

Overload Zero - Real-Time Workload Management System for Last-Mile Courier Drivers

[1] Project Overview
Real-time recognition (HAR) of delivery drivers’ activities using smartphone IMU and ambassador energy (WEEE). Estimation, calculation of the work-stress index (WSI) and thermal environment risk, and rest, routes, and managers. It is a decision-support system that provides monitoring.

[2] Structure 
01_Code_App/app.html (for articles) · dashboard.html (for administrators) · heatmap.html (for maps)
02_Server/ final_server.ipynb  
03_Code_Model  
04_Data/Shipping Information_Coupang_0602.xlsx, HHAR, Phyphox, WEEE, simulation.json
 

[3] Execution method
1) Code_Model: Run it in Colab → Create a model (.pkl)
2) Code server: run on Colab → Issue a public URL (model auto-loaded)
3) Browser access: / (app) · /dashboard · /heatmap
